# 特色

## 发酵桶

<div style={{textAlign: 'center'}}>

![发酵桶](/img/feature-keg.png)

</div>

一种全新的厨具方块，通过精确把控其内部温度来产出各种酒饮、奶酪或腌菜。

内部可存储各种液体，挖掘发酵桶可以将其携带，默认最大 1000mB\* 容量。

横向？竖向？怎么好看怎么摆。

<small>\*mB：miliBuckets，毫桶；每 1000mB 为 1B（Buckets，桶）</small>

## 托垫

<div style={{textAlign: 'center'}}>

![托垫](/img/feature-coaster.png)

</div>

以优雅的方式将物品摆放在各种地方，部分物品还会以 3D 模型的形式展现。

由 CE 驱动，真方块，触手可及；16 向旋转，朝哪放都有面。

潜行右键可以将托垫抽走，物品就像是被直接放下了~

*这小药水真可爱*

## 饮酒

<div style={{textAlign: 'center'}}>

![饮酒](/img/feature-drinking.png)

</div>

不同酒酿拥有不同的状态效果属性，综合搭配或去除它们以获得最佳战斗状态。

- **微醺**：在 III 级或更高时，使屏幕产生摇晃效果。在 IV 级或更高时，你发送的聊天信息将会被打乱。可能会延迟伤害，由橙色的微醺心形表示。
- **酩酊**：使玩家无法从食物中获得饱和度。
- **狂醉**：使你在对实体造成近战伤害时获得 5% 的攻击速度提升。此效果最多可叠加 4 次。
- **甜心**：允许在任何饥饿值下基于额外的饱和度进行额外治疗，同时保留现有的饱和度治疗。
